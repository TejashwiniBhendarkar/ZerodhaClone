#  Zerodha Clone  

A fully responsive **Zerodha Console UI Clone** built using **HTML, CSS, JavaScript, Bootstrap,MongoDB and Recharts**. This project replicates the user interface and basic functionalities of the Zerodha Console platform, including stock holdings, watchlist, and interactive charts.

##  Features  

- **Zerodha-inspired UI** – Clean and intuitive design following Zerodha's Console interface.  
- **Holdings Page** – Displays stock holdings with a detailed table and graph visualization.  
- **Interactive Charts** – Implemented using **Recharts** to visualize stock performance.  
- **Watchlist Feature** – Add and remove stocks from the watchlist.  
- **Buy/Sell Functionality** – Simulated buy/sell actions with modal pop-ups.
- **Database Added**-signup,login,holdings pages using MongoDB.
- **Fully Responsive** – Optimized for desktop and mobile devices.  

##  Tech Stack  

- **Frontend**: HTML, CSS, JavaScript, Bootstrap  
- **Charting Library**: Recharts  
- **State Management**: JavaScript (Vanilla)
